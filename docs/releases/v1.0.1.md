## Why this release

On 2026-10-04, Projects and Payables failed in production, because the code
read custom fields that the new ERPNext site did not have.
`docs/INCIDENT-2026-10-04-schema-skew.md` is the record.

## The scope

The card `docs/tasks/v101-missing-fields.md`, parts A to D: list calls that
operate when a field is absent, "not available" in place of ₹0, removal of the
fields that ADR-0005 does not permit, three diagnostic corrections, the master
records that the code names, and the one schema file on production.
