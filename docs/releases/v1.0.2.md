## Why this release

The design is written as 755 raw colour classes in 28 files. A change to one
colour is a change in many files, and an agent cannot know which value is the
design. `docs/FRONTEND.md` gives each design value one name, in one place.
This release does steps 1 to 3 of its section 9. It comes first in
`docs/RELEASE-2.md`, so that each new screen after it is built one time, on the
tokens.

## The demo test

The test of this release is that **nothing looks different.**

1. Before the work: take a screenshot of each page on demo, in light mode and in
   dark mode, on a computer and on a phone.
2. After the work: take the same screenshots on demo.
3. Compare each pair. Each difference is a fault, or a value that FRONTEND.md
   must record. Write each one in the card.
